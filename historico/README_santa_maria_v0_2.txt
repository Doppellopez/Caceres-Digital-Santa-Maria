Santa Maria v0.2

Contenido:
- santa_maria_v0_2.glb : modelo 3D principal
- santa_maria_v0_2.obj / .mtl : export alternativo
- santa_maria_render_v0_2.png : snapshot del render
- generate_santa_maria_v0_2.py : script de generación
- santa_maria_dxf_local.json : datos DXF ya recortados a la zona

Notas:
- Coordenadas locales en metros, con origen desplazado al entorno de la plaza.
- Es un modelo base procedente de cartografía municipal 3D; las fachadas y cubiertas siguen siendo simplificadas.
- El render se ha generado con Python/matplotlib, no con Blender.
